# 小芽小队 · 风铃谷

延续 Meadowbell 晴日手绘乡野画风的浏览器冒险游戏，首个可玩版本 **v0.1.0**。

**[直接进入游戏](https://caden0626.github.io/windbell-valley/play/)** · [Meadowbell 首页](https://caden0626.github.io/windbell-valley/)

## 可以玩什么

- 和比格犬豆丁探索山坡、菜园、牧场、追风山丘和溪谷五处场景。
- 种植三种作物，安排每天六个行动时段，观察天气并在隔夜后收获。
- 选择修桥或让豆丁寻找门闩，抵达上游，解开水渠谜题并恢复山谷。
- 完成村民委托、收集发现，在牧羊和放风筝挑战中刷新分数。
- 使用键鼠或手机触屏游玩。存档保存在当前浏览器，可导入、导出并恢复备份。

## 本地运行

安装 Node.js 22 或更高版本后，在项目目录运行：

```sh
npm run dev
```

打开 <http://127.0.0.1:8765/play/> 游玩，或打开 <http://127.0.0.1:8765/> 查看首页。无需安装依赖，无构建步骤。游戏使用 JavaScript 模块，请通过这个 HTTP 服务运行。

```sh
npm test
```

## 代码和资产

| 路径 | 内容 |
| --- | --- |
| `dist/index.html` | 原始 Meadowbell 首页与游戏入口 |
| `dist/play/index.html`、`game.css`、`game.js` | 游戏界面、输入和交互 |
| `dist/play/engine.mjs` | 独立游戏规则 |
| `dist/play/art.mjs` | 场景、角色和图集配置 |
| `dist/play/minigames.mjs` | 牧羊与风筝挑战 |
| `dist/play/storage.mjs` | 本地存档、备份和导入导出 |
| `dist/play/assets/` | 原始图片、扩展场景、角色图集、视频、字体与字体许可证 |
| `tests/` | 核心规则测试 |
| `docs/` | 使用说明、整体设计报告及美术记录 |

首页和游戏使用仓库内的本地素材，不依赖原图片 CDN。原始山坡的镜像补边视频保持 100% 宽、112.5% 高、顶部 −6.25% 的对齐方式。系统开启减少动态效果后，不加载场景视频，并关闭被动动画。

## 持续开发与发布

推送到 `main` 后，GitHub Actions 会运行规则测试，将 `dist/` 发布到 GitHub Pages。`.github/workflows/deploy.yml` 也支持手动发布；部署记录见仓库的 Actions 和 `github-pages` 环境。

游戏和所有素材使用相对路径，可以部署在项目子目录。无需服务器、数据库、API 密钥或付费服务。

- [首版使用说明](docs/首版使用说明.md)：操作、存档、玩法与后续开发入口。
- [整体设计报告](docs/风铃谷游戏整体设计报告_v0.1.md) · [PDF](docs/风铃谷游戏整体设计报告_v0.1.pdf)：长线设计与分阶段路线。
- [美术素材与生成记录](docs/美术素材与生成记录.md)：画风标准、用户提供的原图和新增素材的完整生成提示词。
