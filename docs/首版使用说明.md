# 小芽小队 风铃谷首版说明

一个沿用 Meadowbell 手绘动画美术的单人浏览器游戏。原始山坡、菜园、牧场和风筝山丘全部成为可探索的地点，新增溪谷修复事件与两个可重复挑战。

## 开始游玩

已发布站点的游戏入口为 `/play/`，原始官网位于 `/`。本地运行需要 Node.js，无需安装依赖、框架或构建：

```text
npm run dev
```

打开 http://127.0.0.1:8765/play/ 。ES 模块和本地资源需要 HTTP 服务，请通过上述地址游玩。

## 操作

- 点击地面或使用 WASD、方向键行走；点击场景标记互动，E 查看附近对象。
- 空格呼唤豆丁并嗅闻；J 打开日记，M 打开地图，B 打开背包，R 查看休息预览。
- 下方工具栏选择探索、浇水与种植。空花床可选种子，成熟作物可收获。
- 手机可轻扫查看场景，通过工具栏与地图进入全部操作；横屏时场景视野更宽。

## 本版本内容

五处地点、男孩与比格犬四朝向移动、嗅闻与取物、两条独立上游路线、四格菜园、三种植物、雏菊邻接加成、豆类轮作、水槽拼接、三种分水方式、晴雨预报、六时段日程、完整第一章、村民委托、花床边框、自然发现与日记。

牧场赶羊和风筝挑战可反复游玩，包含普通计时与不计时练习。首次完成送种子，后续记录最佳成绩，奖励不会反复发放。

## 存档

自动使用 IndexedDB 保存，并保留三个轮换备份；localStorage 提供额外恢复途径。设置中可导出、导入与恢复备份。进度仅属于当前设备和浏览器；清理浏览器数据前请导出。版本 0.1 没有账户或云同步。

## 项目结构

```text
dist/index.html             原始官网与游戏入口
dist/play/index.html        游戏界面
dist/play/game.css          视觉与响应式布局
dist/play/engine.mjs        时间、资源、种植、水路、任务规则
dist/play/game.js           场景交互、移动、界面与音频
dist/play/art.mjs           地点配置与手绘图集渲染
dist/play/minigames.mjs     赶羊与风筝挑战
dist/play/storage.mjs       保存、备份与导入导出
dist/play/assets/           原始参考、可玩场景、角色、植物和字体
tests/engine.test.mjs       关键规则回归测试
docs/美术素材与生成记录.md  美术来源、使用路径与完整生成提示词
```

## 检查

```text
npm test
```

测试覆盖两条路线独立通关、失败不扣资源、过夜成长、分流不累计、雏菊邻接、豆类肥沃、免费种子恢复、奖励不重复、每日委托、存档校验和导入数据处理。浏览器验证覆盖完整主线、小游戏实际操作、手机布局、减少动态效果和保存重载。

## 继续开发

新增地区从 `art.mjs` 的地点和素材配置开始。世界事实与任务条件放在规则层，页面负责呈现结果。新增存档字段提供默认值；变更结构时提升版本并增加迁移与旧档测试。资源、角色比例、光照与笔触遵循美术记录中的基准。

原有整体设计报告在工作区 `game-design` 目录。本版在设计报告的家园与溪谷基础上加入原图对应地区及两个独立挑战；它是可以持续扩展的第一章版本。
