# 风铃谷美术素材与生成记录

版本 0.1.0，2026 年 10 月 22 日。

## 持续遵循的美术方向

本项目延续用户提供的 Meadowbell 图像。场景保持蓝天、厚实积云、暖黄绿色草地、远景山谷和可见的手绘笔触。男孩保留乱棕发、浅色短袖与蓝短裤，比格犬保留棕白毛色和垂耳。新素材使用同一光向、自然比例和柔和边缘，游戏中的主体不改为像素、扁平矢量或三维渲染。

原始素材完整保留。菜园与牧场的可玩版本是参考原图的局部编辑；山坡原图与视频承担休息和标题画面，风筝山丘原图保留阿葵。UI 图标、操作标记和解谜目标是界面元素，与场景原画分开。

以下五项均由内置 image_gen 工具生成或编辑，并已复制到游戏项目中。未使用命令行 API 生成。角色图集使用纯洋红色作为运行时色键，浏览器在内存中去除背景并裁取角色与植物；原始生成文件保持不变。

## 后续素材验收

新增素材必须先与菜园、牧场和标准角色并排检查。检查云形、草地色相、光向、笔触密度、角色身高、狗与男孩的比例，以及缩小到实际游戏尺寸后的可读性。可操作背景应提供空的角色活动区域，植物、人物与小物件使用独立资源。资源使用永久 ID，避免更新时破坏旧存档。
